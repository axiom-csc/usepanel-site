# usepanel-site

Static marketing site for usepanel.dev. Plain HTML/CSS generated by a dependency-free Node script. No server, no cookies, no analytics. One small script on /pricing reads the founding-spot count from the Panel Cloud API.

Pages: `/`, `/how-it-works`, `/evals`, `/design-partners`, `/pricing`, `/security`, `/privacy`.

```
npm run build   # node build.mjs  -> ./dist
npm run check   # internal links, anchors, mailto, title/description on every page
npm test        # build + check
```

Edit content in `src/pages.mjs`, styles in `src/site.css`, the shared header/footer in `build.mjs`.

## Cloudflare Pages
- Framework preset: None
- Build command: `npm run build`
- Build output directory: `dist`
- Root directory: `/` (blank)
- Environment variable (optional): `NODE_VERSION=20`

## Numbers
Action-firewall numbers come from `results/llm_report.md`, `results/claims_v2_report.md` and `results/eval/latency.json` in panel-firewall-public (test count from `pytest`). Support-bot numbers come from `GUARD_README.md` (fresh6/7/8). Update `src/pages.mjs` (home stats and `/evals`) when a newer set becomes the headline.

## Forms
The design-partner application and early access are `mailto:` links with a prefilled body. The address is `EMAIL` in `src/pages.mjs`.
